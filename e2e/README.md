# 회귀 테스트 (e2e)

사이트를 고친 뒤 "다른 곳이 깨지지 않았는지"를 한 번에 확인하는 점검 모음입니다.
사이트 빌드(Vercel)와는 따로 설치하므로 배포에는 영향이 없습니다(`.vercelignore` 에서 제외).

## 처음 한 번

```bash
cd e2e
npm install
npx playwright install chromium   # 이미 크롬(Chromium)이 있으면 CHROMIUM_PATH=/경로/chrome 로 대신해도 됩니다
```

## 돌리기

```bash
cd e2e
npm test                    # 전부 — 약 15~20분
npm run test:quick          # 빠른 점검(pages · films · api) — 약 5분
npm test -- menu            # 하나만 고르기
BASE=https://miraeailab.com npm test -- pages   # 운영 사이트를 그대로 점검
```

개발 서버(127.0.0.1:4580)가 떠 있지 않으면 `run.mjs` 가 알아서 띄우고, 끝나면 닫습니다.
마지막에 테스트별 `통과 N · 실패 M` 합계가 나오고, 하나라도 실패하면 종료 코드가 1입니다.
스크린샷은 `e2e/.out/` 에 남습니다(저장소에는 올리지 않음).

## 무엇을 보나

| 이름 | 확인하는 것 |
|---|---|
| `pages` | 주요 31개 주소 × 폰·PC — 스크립트·콘솔 오류, 못 받은 파일, 깨진 이미지, 가로 넘침, 휴대폰 맨 아래 띠 색(반짝임 방지) |
| `films` | 컨설턴트 페이지 영상 '준비 중'·출시 알림 신청 폼(빈 칸 막기·보내는 내용·스팸 함정 칸), AX 페이지 끝 실제 프로젝트 영상(파일·재생·속도) |
| `a11y` | 접근성(axe-core) — 주요 13개 페이지에 '심각·치명' 위반 0개 |
| `menu` | 햄버거 메뉴 — 항목 순서, 실제 이동, 구간이 헤더에 안 가리는지, 뒤로가기, 닫기, 상담 창, 로그인 연결 |
| `api` | 서버 함수 입력 검사 — 이상한 값에 멈추지 않는지, 스팸 함정 칸, 내부 오류 원문·환경변수 이름이 응답에 안 나가는지, 휴대폰 문자 인증이 닫혀 있는지 |

## 주의

- 바깥 주소(구글·카카오·글꼴 CDN)는 막고, 글꼴은 `pretendard` 패키지에서 바로 씁니다 — 매번 같은 화면으로 비교하려고요.
- `/api/**` 요청은 가짜 성공 응답으로 바꿉니다. 실제 메일·DB 는 건드리지 않습니다.
- 화면 문구를 일부러 바꿨다면(예: 메뉴 이름) 해당 테스트의 기대값도 같이 고쳐 주세요.
