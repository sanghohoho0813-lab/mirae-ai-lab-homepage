## 신뢰성 표기 원칙

- 모든 화면은 "가상 업종 기반 프론트엔드 프로토타입 예시"로 표기하며 "성공사례·실제 고객사·실제 운영 화면" 표현을 쓰지 않는다.
- 화면 속 상호·수치·제조사명(두산·PUMA 등 장비 매물 표기 포함)은 시연용 가상 데이터임을 라이트박스·갤러리 하단에 고지한다.
- 사진 9·32·44·56(도입 전후 효과 수치 포함)은 허위 수치 오인 방지를 위해 웹사이트에 사용하지 않는다.
