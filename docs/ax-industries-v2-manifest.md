## 5장의 이야기 순서

모든 업종이 동일한 5단계 서사를 따른다.

1. **운영 손실 발견** — 숫자를 다시 보여주는 것이 아니라 손실이 반복되는 지점을 찾는다
2. **오늘의 실행** — 오늘 먼저 처리할 일을 우선순위로 정리한다
3. **매출 기회** — 놓치고 있던 고객·주문·견적을 다시 매출로 연결한다
4. **반복매출** — 내부 관리에서 끝내지 않고 반복·계약·구독 구조로 확장한다
5. **실제 활용 예시** — 활용 예시 1·2 (기존 / AX 적용 / 기대 변화)

5번째 이미지에 업종별 활용 예시 2개가 이미 인쇄되어 있어, 30개 사업화 아이디어 카드의
`기존 문제 · AX 적용 · 기대 변화`는 이 원본 이미지 내용을 출처로 사용한다.
