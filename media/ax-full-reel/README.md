# AX 풀 구축 소개 영상 (릴스 9:16) 원본

AX 트랙 페이지에 넣을 소개 영상의 원본입니다. 대본은 대표님 최종 수정본(`spoken.txt`, 흐름은 `script-v3.md` 참고)이고,
[HyperFrames](https://github.com/heygen-com/hyperframes) 로 만듭니다. 기술사업·MVP 영상(`media/venture-mvp-reel/`)과 같은 틀입니다.

- 지금 결과물은 **녹음 전 자막판**(약 4분 13초 = 말 4분 7초 + 끝 화면 5초, 소리 없음)이에요.
  말 시간은 기술사업·MVP 녹음의 실제 속도(쉼을 뺀 말 속도 초당 약 7.45글자 · 쉼표 0.2초 · 문장 0.35초 · 장면 0.45초)로 어림했어요.
- 녹음을 받으면 받아쓰기만 바꿔 끼우면 장면·강조·자막이 목소리에 맞춰 다시 정렬돼요(아래 '다시 만들기').

## 파일

| 파일 | 내용 |
|---|---|
| `spoken.txt` | 대본(= 자막). 빈 줄로 장면(13개), `\|` 로 자막을 직접 끊는다 |
| `keys.json` | 장면 안 강조 타이밍에 쓰는 핵심 단어 |
| `synth_asr.py` | 녹음 전 — 대본으로 가상 받아쓰기(`asr-synth.json`)를 만든다(말 속도 인자) |
| `asr.py` | 녹음 후 — faster-whisper 로 진짜 받아쓰기(`asr.json`) |
| `align.py` | 받아쓰기 ↔ 대본 글자 단위 정렬 → `timing.json` |
| `build.mjs` | `timing.json` → `index.html`(컴포지션) · `subtitles.srt` |
| `flow.mjs` · `convert_flows.py` | 데모를 실제로 눌러 가며 찍기(입력칸 채우기 `fill` 지원) → `assets/flows/`(누른 위치 `flows.json`) |

## 다시 만들기

```bash
# 녹음 전(지금)
python3 synth_asr.py . 7.45 && ASR=asr-synth.json python3 align.py . spoken.txt keys.json
# 녹음 후 — voice.mp3 를 넣고
python3 asr.py . && python3 align.py . spoken.txt keys.json      # (쉼 정리·1.05배는 venture-mvp-reel 의 tighten.py 를 그대로 쓸 수 있어요)
node build.mjs
npx --yes hyperframes@0.8.79 render --fps 30 --quality high -o renders/ax-reel.mp4
```

## 지켜야 할 것

- 사례는 **공개 사례 요약 · 미래AI랩 실적 아님**, 정책은 **공식 근거** 상자로 따로 — 미래AI랩 데모·실적과 섞지 않는다.
- 인증은 **'신청까지 함께 준비'**, 결과·처리기간은 외부기관 심사라는 각주를 단다. 특허는 **'출원'** 만(등록·보유 금지).
- 실제 프로젝트는 회사 이름 없이 업종만. AX 화면은 예시 화면(Concept Prototype) · 가상 시연 데이터.
- 심사장 장면은 연출이다(실제 심사 기록 아님). 승인·선정·금액을 약속하는 말은 쓰지 않는다.
- '250곳 이상 · 수억~수백억 원'은 대표님 조사 기준 — 사이트 AX 상세 안내(6-1: '200개 넘는 기업')와 숫자를 맞춰야 한다.
