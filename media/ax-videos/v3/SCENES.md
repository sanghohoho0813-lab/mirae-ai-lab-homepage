# 실제 프로젝트 1·2편 — 영상 스타일 v3 장면표

기준: `VIDEO_STYLE_GUIDE_V3_FINAL.md` — **크게 · 적게 · 시각 메타포 먼저**.
음성(1.13배 · 쉼 줄임 · -14 LUFS)과 자막 정렬은 v2와 같은 규칙이라 `v2/real-ep*/` 의 최종 음성·정렬을 그대로 쓴다.

- 배경: 뜻에 따라 고른다. 감정·문제·전환·허브/순환도 = 어두움(D), 숫자·실제 화면·단계·비교 = 밝음(L). 같은 톤은 최대 2장면 연속.
- TYPE: A 큰 문장 · B 큰 도식 · C 큰 기기 화면 · D 차례로 등장 · E 바뀜(BEFORE→AFTER) · F 숫자 · G 마무리. 같은 TYPE 3장면 연속 없음.
- 한 장면 = 큰 제목 1 + 큰 시각 요소 1 + 보조 0~3. 화면 글은 요약만, 설명은 자막이 맡는다.
- 실제 화면은 이름을 ○○ 로 가린 캡처만, 짧게. 그 밖의 앱 모양은 예시 데이터로 다시 그리고 표기한다.
